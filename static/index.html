        About

        Cyber Security News Powered by AI

        A local cyber-intelligence briefing. It collects recent reporting from the sources you configure, summarises and classifies each article, and stores everything in a full-text index you can search and filter by time, topic and source.

        Your data is kept

        Every collected article is saved in a SQLite database and is still there after you stop the app, restart it, reboot the server or rebuild the Docker image — no need to collect again.

        Stopping is safe: the app lets a running refresh finish and flushes the database first. Back up by copying the data folder, or run python3 server.py --backup backup.db (Docker: docker compose exec pulse python server.py --backup /app/data/backup.db).

        How news is refreshed

        • Manually, by the analyst: Refresh news collects from all enabled sources, one source, or several chosen sources.
        • Automatically, by the application: once a day for all enabled sources, using the look-back window and the per-source article limits from Manage sources.
        • Both add only articles not already stored, so nothing is duplicated.

        Running it

        • Docker Compose (recommended): docker compose up -d --build. Published on your LAN address, by default http://192.168.3.100:8000. Settings go in .env.
        • Python: python3 server.py --host 192.168.3.100. Use 127.0.0.1 for this machine only or 0.0.0.0 for every interface.
        • Both use the same data folder, so you can switch between them without losing news.
        • There is no login: anyone who can reach the address can use the app, so keep it on a trusted network.
